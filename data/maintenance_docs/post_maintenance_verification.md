# Post-Maintenance Verification and Baseline Reset
## Verification run
After repair, run the machine and compare vibration, temperature and power draw against the previous healthy baseline. Values should return to baseline within a defined run-in period.
## Baseline reset
After a bearing replacement or realignment the healthy baseline may change slightly. Record a fresh baseline so future alarms are judged against the repaired condition.
## Sign-off
A technician signs off the work order with measurements. If values do not return to baseline, reopen the order and investigate further.
